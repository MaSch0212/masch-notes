# goast notes (found while building MaSch Notes)

Issues in the generators that this repo works around in hand-written code. Generated code is never edited.

| Package                                 | Issue                                                                                                                                                       | Workaround here                                                                                                                                                |
| --------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `@goast/typescript` 0.9.1 fetch clients | `multipart/form-data` request bodies are sent with `JSON.stringify(body)` instead of `FormData` (see `AiClient.createAiJob`).                               | `client/src/lib/ai-jobs.ts` uploads with its own `fetch` + `FormData`.                                                                                         |
| `@goast/typescript` 0.9.1 fetch clients | `UrlBuilder.build()` does not compile with `noUncheckedIndexedAccess` (`this.pathParams[name]` is `string \| undefined`).                                   | `noUncheckedIndexedAccess` is off in `client/tsconfig.json`.                                                                                                   |
| `@goast/typescript` 0.9.1 fetch clients | JSON request bodies are sent without a `Content-Type: application/json` header; query values are not URL-encoded.                                           | Go server accepts a missing media type as JSON; `client/src/lib/api.ts` adds the header via `options.headers`. Only date/number/boolean query values are used. |
| `@goast/go` 0.1.1                       | A schema named `RenameNotebookRequest` collides with the generated request type of operation `renameNotebook`, which becomes `RenameNotebookRequestObject`. | Accepted as is.                                                                                                                                                |
